Frequently asked questions

Is FormatLab free?

FormatLab is free to download and use for everyday conversions. A one-time Pro upgrade unlocks unlimited batch queues and the full feature set — there is no subscription.

Does FormatLab upload my files anywhere?

No. All conversion happens locally with FFmpeg on your own machine. There is no upload, no file-size cap and no server-side queue, so it works offline and with confidential footage.

Does FormatLab work on Ubuntu, Fedora and Arch?

Yes. Install it as a Snap, a Flatpak from Flathub, or a portable AppImage that runs on essentially any modern Linux distribution.

Can it convert 4K and 8K video?

Yes. FormatLab handles sources up to 8K, and GPU acceleration keeps large UHD encodes practical.

Can it convert multiple files at once?

Yes. Drag in a whole folder, set the output format once, and FormatLab converts the entire queue.

Does it keep 5.1 or 7.1 surround sound?

Yes. Multi-channel audio is preserved rather than downmixed to stereo.

Does converting lose quality?

Any lossy re-encode loses some quality. FormatLab exposes bitrate and quality controls so you can stay visually lossless, and format-only changes such as MKV to MP4 can often be done without re-encoding the video stream.

Is FormatLab open source?

No. FormatLab is a proprietary desktop application built on FFmpeg. The GitHub repository hosts releases, packaging metadata and the issue tracker rather than the application source.
